# Winter Loop

A two-day winter road trip site: itinerary, route map, motels, packing, and cost splitting. Vite, React, TypeScript.

    npm install
    npm run dev

`node scripts/build-map.mjs` regenerates the map. `npm run build` writes `dist`, which is published to the `gh-pages` branch.

Names and costs are never in this repository. They stay in each browser, or after the # in a link made by Share Trip.

Photographs are from Wikimedia Commons under CC BY and CC BY-SA; credits are in the site footer. Routes © OpenStreetMap contributors.
